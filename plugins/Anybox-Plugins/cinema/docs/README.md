# Cinema documentation archive

The authoritative Cinema Runtime 1.0 build, data, security, and release instructions are in the plugin-root `README.md`, the current manifest, and executable tests.

Files in this directory preserve earlier UI decisions, audits, screenshots, and pre-1.0 Deliver evidence. They are not included in the Cinema 1.0 plugin ZIP and must not be used as a source for Runtime paths, environment variables, Provider ownership, or release commands.
