# Godot CLI v0.6.0 发布说明

Godot CLI v0.6.0 面向 Godot 4.6.x 和 Windows x86_64，在保持 loopback 认证 TCP、protocol v1、独立 `apply` 确认和现有输出 envelope 不变的前提下，完成资源组合最小闭环。公开插件工具由 33 个增加到 37 个：16 个读取工具、21 个写入工具。

## 新增能力

- `resource list` / `list_project_resources`：从 EditorFileSystem 当前快照按类型、扩展名和目录发现项目资源，返回导入状态、脚本类元数据、可赋值族及稳定分页。
- `resource inspect` / `inspect_resource`：加载并检查一个非脚本化 Resource 的实际类型、资源元数据和有界安全属性。
- `node assign-resource` / `assign_resource_property`：把已有项目资源引用赋给兼容的本地节点属性。
- `node create-subresource` / `create_subresource_property`：创建一个新的白名单内 SubResource，配置最多 32 个安全初始属性后赋给节点。
- CLI 新增独立 `resource` 领域，并为两个资源写工具提供专用节点子命令；所有命令继续支持单对象 JSON 输出和 CLI 任务轨迹。

## 类型边界

外部资源赋值只接受七个声明族：

- `Texture2D`
- `Shape2D`
- `AudioStream`
- `Font`
- `Theme`
- `StyleBox`
- `PackedScene`

实际资源必须继承节点属性的具体声明类型并落在同一族。通用 `Resource` 属性、Script、自定义脚本资源和实例附带脚本均被拒绝。

SubResource 创建只接受五个精确类型：

- `RectangleShape2D`
- `CircleShape2D`
- `CapsuleShape2D`
- `SegmentShape2D`
- `StyleBoxFlat`

初始属性沿用既有安全标量和精确 `Vector2/2i`、`Vector3/3i`、`Color`、`Rect2/2i` 编码；`script`、`resource_path`、`resource_scene_unique_id` 始终不可写。

## 安全与事务语义

- 两个读取工具不会触发 EditorFileSystem 扫描或导入；外部文件发生有意变更后，需要另行确认 `game rescan --apply --wait`。
- 两个写工具都需要独立 `--apply`，并要求目标是当前场景根或由场景根直接拥有的本地节点。
- 全部路径、类型、脚本、属性、旧引用和初始值在提交前完成预检。
- 每个成功写入只创建一个以场景根为上下文的 UndoRedo 动作；Undo/Redo 保持同一个 Resource 实例引用。
- 写入只改变编辑器内存并标记场景未保存；不会创建、覆盖或修改 `.tres`、`.res` 等外部资源文件，不会隐式扫描、导入或保存。
- 提交后重新核验节点身份、owner、属性引用和未保存状态；后置失败时先恢复旧引用，无法证明安全回滚才返回 `INTERNAL_ERROR`。

## 兼容性

- 传输协议仍为 v1；帧格式、会话发现、认证、JSON-RPC 方法、工具执行 envelope 和退出码保持兼容。
- 现有 33 个插件工具的名称与业务参数保持不变。
- `node set` 和 `node set-batch` 的通用安全值范围不变；Resource 必须使用两个专用写工具。
- 插件与 CLI 应同时升级到 v0.6.0；替换文件后重启 Godot 编辑器，使新会话记录带上匹配版本。

## 明确不包含

v0.6.0 不创建或编辑外部 Resource 文件，不修改共享 Resource 内容，不提供任意 Resource 类型、Shader、Animation、SpriteFrames、TileSet、嵌套资源、数组或 Dictionary 写入，也不增加 MCP、HTTP、Autoload 探针、任意代码执行或后台保存。

- 37 个工具的关闭输入/输出 Schema 与运行时黄金契约；
- Rust CLI 解析、JSON 映射、命令目录、`--apply` 元数据和黄金报告；
- GUT 路径守卫、EditorFileSystem 查询、脚本拒绝、类型族匹配、初始属性、owner、UndoRedo 与失败回滚；
- 真实 Godot 编辑器中的 SVG/Texture2D 外部赋值、RectangleShape2D 内嵌创建、同实例 Undo/Redo、保存前磁盘 SHA-256 不变、显式保存后的 `ext_resource`/`sub_resource` 序列化，以及运行/停止；
- `cargo fmt`、Clippy、Rust 测试、GUT、集成测试、发布构建、静态 CRT 检查、ZIP 安装烟雾和 SHA-256 清单。
