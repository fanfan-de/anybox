# Anybox Original Logo Replica

This package faithfully vectorizes the user-confirmed source logo at
`packages/site/public/anybox-box-cat-logo.png`.

- Canvas: 1024 × 1024
- Geometry: one compound path with 10 subpaths
- Embedded raster images: none
- Live text: none
- Binary silhouette IoU against the source: 99.06%
- The original transparent margins and artwork placement are preserved

Files:

- `anybox-original-logo-white.ai`: editable Adobe Illustrator document
- `anybox-original-logo-white.svg`: primary white transparent vector
- `anybox-original-logo-black.svg`: black transparent vector
- `anybox-original-logo-white-1024.png`: white transparent PNG
- `anybox-original-logo-black-1024.png`: black transparent PNG
- `validation.json`: automated comparison results
- `preview.html`: source/vector comparison page
