# Forms

## 表单布局

表单根据任务选择布局：

- 配置项：row-first，左侧标题和说明，右侧控件。
- 创建/编辑实体：label 在上，控件在下，按字段分组。
- 批量参数：紧凑 grid，保留清晰 label。
- 危险操作：独立区块，说明后果，动作按钮明确 danger。

设置行和表单行默认单行扫描。不要在普通行里放 label 下面的说明文字。字段说明只在影响决策时显示，或放到 tooltip、详情区、文档入口。

## Label 与 Helper

label 简短明确。不要给每个字段默认添加 helper text。只有当字段存在风险、限制、错误、权限影响或不解释会导致误操作时，才显示辅助文案。错误信息贴近字段，使用语义错误色，并提供可理解文本。

## 保存状态

保存、同步、应用、重置要有明确状态：idle、dirty、saving、saved、failed。不要只靠按钮禁用表达状态。

## 校验

即时校验适合格式错误和必填项；提交校验适合跨字段逻辑。错误状态要可被屏幕阅读器感知。

## 复杂配置

复杂配置不要堆成长表单。用 section、accordion、tabs 或 detail pane 分组。高级选项默认收起，但搜索或错误定位时要能展开。

## 危险操作

删除、清空、重置、断开连接、覆盖配置必须用独立 danger 区域或 dialog。按钮文案写具体动作，不要只写“确认”。
