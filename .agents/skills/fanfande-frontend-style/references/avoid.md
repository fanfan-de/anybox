# 避免项

## 视觉反模式

- 营销落地页式 hero、超大标题、分屏宣传图。
- 装饰性渐变、光斑、玻璃拟态、厚重阴影。
- 大面积品牌色背景或单一色系铺满。
- 给所有按钮添加默认 1px 边框。
- 在核心产品 UI 里使用原生 `<select>`，导致展开态出现系统蓝色选中和不可控 option 样式。
- 用大量文字 badge 表达常见状态，例如 Active、Paused、Needs review。
- 卡片套卡片、panel 套 panel、无意义边框层层包裹。
- 过度圆角，尤其是所有控件都 pill。
- 为了“高级感”降低对比度到不可读。

## 交互反模式

- hover 改变尺寸导致布局跳动。
- 禁用按钮但不解释原因。
- 在 button 中同时放 icon 和文字，例如一个时钟图标加“立即运行”。
- icon-only 操作没有 tooltip 或 aria-label。
- 只靠颜色表达错误、选中或危险。
- 自定义菜单吞掉输入框和 webview 的原生右键菜单。
- dialog 关闭后焦点丢失。
- 长任务只显示无限 spinner，没有阶段、日志或取消路径。

## 信息架构反模式

- 用卡片网格承载需要比较的大量数据。
- 把所有配置堆进一个无分组长表单。
- 在标题、section、panel、card、表格行和设置行下面默认添加解释性小字。
- 在列表行、表格行、设置行、任务行中使用“主标题 + 灰色说明”的双行内容。
- 在紧凑菜单和列表行里常驻长说明。
- 让空状态承担产品宣传，而不是告诉用户下一步。
- 混用 selected、active、checked、current。

## 代码实现反模式

- 绕过现有 token 直接写 hex。
- 新建重复的 button/menu/input 样式。
- 用业务页面 class 污染全局基础组件。
- 未检查 dark theme、brand theme、窄视口和长文本。
- 忽略 Electron `-webkit-app-region`，导致按钮或输入不可点。
