# Menus

## 菜单类型

- context menu：右键或上下文操作
- dropdown menu：按钮触发的短动作菜单
- select menu：选值
- command menu：搜索命令和跳转
- overflow menu：工具栏收纳

## 外观

菜单使用 elevated surface、轻边框、8px 左右圆角、轻阴影。菜单项默认透明，只有 hover、focus、active、selected、highlighted 显示背景。

短菜单不要使用过宽的通用 min-width。图标 + 短文本菜单应按内容宽度推断，并保留 viewport max-width。

## 菜单项

菜单项使用固定高度或 min-height，包含固定图标槽、文本槽、可选快捷键槽、可选状态槽。长文本省略。危险项使用 danger 语义色，不靠位置暗示。

## 搜索菜单

带搜索的菜单语义上可以是 dialog + searchbox + listbox。搜索框固定在顶部，结果区滚动。不要为了套普通 menu role 牺牲输入框可访问性。

## Canvas 风格可搜索下拉

用于技能、MCP、窗口目标、模型、数据源等短标签触发的选择器时，优先参考 canvas 顶栏里的轻量下拉样式：

- 触发器是紧凑纯文字按钮，当前打开时使用浅色选中背景。不要在文字触发器里再放 chevron 图标。
- 触发器和菜单项都不要使用按钮边框。
- 浮层宽度按内容控制，常见宽度约 220px，不要继承宽菜单或 command palette 的尺寸。
- 浮层使用浅灰或面板混合背景、1px 细边框、约 7px 圆角，不使用厚重阴影。
- 顶部搜索框高度约 30px，边框可以使用低饱和品牌色提示可输入状态，placeholder 使用柔和品牌色或 muted text。
- 列表项为纯文本行，约 32px 到 34px 高，左内边距约 10px；默认无背景，hover/focus 才显示轻灰背景。
- 不显示常驻说明、小字、图标和快捷键，除非当前菜单确实需要它们。
- 短列表不显示 scrollbar；长列表允许内部滚动但尽量隐藏可见 scrollbar。

## Canvas 风格普通选择器

运行模式、主题、排序、过滤条件等普通枚举选择，也要沿用 canvas dropdown 的视觉系统。不要因为选项少就回退到原生 `<select>`，否则展开态会出现系统蓝色选中、系统边框和不可控 option 样式。

- 触发器是无边框纯文字 button，宽度填满表单槽位或按内容收缩。
- 展开层用同样的浅灰面板、细边框、约 7px 圆角和轻量选项行。
- 选中项用轻背景或品牌色文字，不用系统蓝色高亮。
- 选项行不放解释小字，不放默认图标，除非枚举本身需要视觉区分。

## 右键菜单

默认保留输入框、textarea、contenteditable 和 webview 的原生右键菜单，除非产品明确接管。自定义右键菜单要处理视口边缘定位、键盘关闭、焦点恢复和禁用项。

## 快捷键

快捷键显示使用 mono 或专用 kbd 样式，右对齐固定槽位。不要让快捷键文本挤压主标签。

## 滚动

短菜单默认不显示滚动条，也不预留滚动条槽位。只有结果可能超过视口时才内部滚动，并尽量避免可见 scrollbar 破坏紧凑布局。
