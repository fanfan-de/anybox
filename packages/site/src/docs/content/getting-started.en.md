# Quick Start

Anybox is a desktop AI agent workspace for local projects. Open a project folder, create a session, and let an agent read code, carry out tasks, call tools, and track changes inside the current workspace.

## Install

The website provides installers for Windows x64, macOS Apple Silicon, Linux x64, and Android. Select the matching download button on the home or documentation page to open the latest installer for that platform. The Linux release provides an AppImage, with a Debian package also available from GitHub Releases.

```text
Platform status
Windows x64: Early Access
macOS Apple Silicon: Early Access
Android: Early Access
Linux x64: Early Access (full Cinema/Deliver)
```

Launch Anybox after installation. If your operating system displays a security prompt, confirm that the installer came from the project's GitHub Releases page.

## First Launch

1. Open Anybox.
2. Choose a local project folder as your workspace.
3. Configure a model provider and model in Settings.
4. Create a session and describe the task you want the agent to complete.

## Basic Workflow

The core Anybox workflow is organized around project folders and sessions:

- A workspace maps to a local project folder.
- A session preserves one agent collaboration thread.
- Terminal output, tool calls, patches, and errors appear in the session.
- For higher-risk operations, the app asks for confirmation through its permission workflow.

## Next Steps

After installation, continue with model provider configuration. Once a model works, create Skills for repeated workflows so the agent can follow your project conventions more consistently.
