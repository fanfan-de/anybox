# 什么是 Anybox

Anybox 是一款开源的 AI Agent 桌面工作台，面向软件开发与日常办公。它把项目文件、会话、模型、工具和权限放在同一处，让 Agent 能围绕真实项目持续执行任务，而不只是回答问题。

## 核心能力

- **软件开发**：理解代码、定位问题、修改文件并运行测试。
- **研究与办公**：整理资料、比较方案、分析数据并输出文档。
- **内容创作**：编写文案、脚本、页面草稿和执行计划。

实际能力取决于操作系统、当前工作区、所选模型，以及已启用的工具、MCP 和插件。

## 工作方式

| 概念 | 作用 |
| --- | --- |
| 项目 | 提供文件目录和工作边界 |
| 会话 | 保存一次持续协作及其执行记录 |
| 模型 | 理解目标并决定下一步 |
| 工具 | 读取、搜索、执行或修改 |
| 权限 | 在必要时询问、允许或阻止操作 |
| Skill / 插件 | 提供可复用流程和扩展能力 |

## 开始使用

1. 打开一个本地目录或 Git 仓库。
2. 在“设置”中连接服务商并选择模型。
3. 新建会话，说明目标、范围和完成标准。
4. 检查工具调用、文件变更和验证结果。

首次使用建议从只读任务开始：

> 阅读 README 和目录结构，说明项目如何启动，暂时不要修改文件。

## 数据与权限

打开项目不等于授权所有操作。工具可用性、Agent 策略、会话限制和调用级审批会共同决定操作能否执行。

使用云端模型、远程 MCP 或 Connector 时，任务所需内容可能离开本机。不要在会话、项目、Skill 或插件中写入 API Key、令牌、密码等敏感信息。
