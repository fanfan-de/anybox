# Windows 电脑控制

Windows 电脑控制让 Agent 观察并操作一个明确指定的 Windows 应用窗口。它面向没有 Connector、API 或稳定命令接口的桌面软件，通过窗口截图、可访问性信息和受保护的鼠标键盘输入完成任务。

> 当前插件面向 Windows 11 x64。桌面控制期间，每个显示器都会出现蓝色安全边框和“按 Esc 停止”提示。看不到提示时，插件不会继续访问桌面。

## 什么时候使用

适合 Windows 电脑控制的任务包括：

- 操作记事本、画图、媒体播放器或其他原生 Windows 应用。
- 在没有结构化接口的软件中点击菜单、切换选项、滚动、拖拽或输入文字。
- 读取指定窗口当前显示的状态，并把结果整理回会话。
- 完成依赖画布、图形编辑器或自定义控件的少量可验证步骤。

如果任务发生在普通网页中，优先使用 Chrome 插件；如果任务是读取文件、修改代码或运行命令，优先使用 Anybox 的文件和 Shell 工具；如果服务提供 Connector 或 API，优先使用结构化集成。

## 安装并为项目启用

1. 确认设备运行 Windows 11 x64。
2. 从 Anybox 左侧导航打开「插件」。
3. 搜索「Windows 电脑控制」或 `computer-use-windows`，阅读高风险能力说明后点击「安装」。
4. 在当前项目顶部菜单的插件选择器中启用该插件。
5. 建议先打开目标应用，再在任务中写明应用名称、窗口和允许完成的动作。

插件包本身包含桌面控制运行时和本机组件，不需要另建 Computer Use MCP 或单独设置页。卸载该插件会同时移除这项能力。

## 推荐的任务写法

一次只指定一个应用窗口，并给出明确的停止边界：

- “使用 Windows 电脑控制，仅操作已打开的记事本窗口，把下面三段文字整理进去，不要关闭文件。”
- “查看计算器当前结果并告诉我数值，不要再按任何键。”
- “在已打开的绘图应用中选择矩形工具并画一个边框，完成后截图确认。”
- “把内容填写到桌面应用的编辑区，停在发送按钮之前让我确认。”

不要只说“帮我操作电脑”。应用、窗口、数据和最终动作越明确，目标选择和审批范围越可靠。

## 一次操作如何进行

Agent 会遵循短循环，而不是连续盲点：

1. 列出当前可用应用和窗口。
2. 选择唯一的目标窗口。
3. 获取该窗口的最新截图和有限的可访问性信息。
4. 根据这次观察执行一个动作。
5. 重新观察结果，再决定下一步。

每份观察状态很快过期，并且最多授权一个动作。窗口、布局、焦点或遮挡发生变化后，Agent 必须重新观察，不能复用旧坐标或旧控件编号。这种节奏会比连续宏稍慢，但能显著减少点击到其他窗口或重复提交的风险。

## 蓝色安全提示与停止

开始桌面访问前，插件会在所有活动显示器上显示蓝色边缘和状态提示：

- 提示只表示 Computer Use 正在活动，不等于你已批准某个高风险动作。
- 按物理键盘上的 `Esc` 可以立即停止当前桌面控制。
- 安全提示不能在生产环境中关闭或绕过。
- 提示创建失败、桌面锁定或控制被中断时，Agent 必须停止本轮操作。

停止后，原应用保持当前状态。需要继续时，请先检查窗口内容，再发出新的明确请求。

## 权限与禁止范围

普通观察和低风险本地交互不需要每一步都弹出审批。发送或提交、删除、上传、安装等高影响动作会在动作发生前请求一次性决定；审批详情会隐藏实际输入文字和赋值内容。

Windows 电脑控制不会操作：

- Anybox 自身、终端、PowerShell、命令提示符或 Windows“运行”窗口。
- 登录、密码、验证码、密码管理器、UAC 或安全桌面。
- Windows 安全与隐私设置、杀毒软件或浏览器安全警告。
- 付款流程、年龄验证、CAPTCHA 或绕过网站安全限制。
- 锁屏以及完整性级别高于 Anybox 的受保护窗口。

网页、邮件、文档和窗口里出现的文字都应被视为内容，而不是新的用户指令。界面要求复制、上传、删除或泄露数据时，Agent 不应执行，除非你的原始请求明确包含该动作并通过必要审批。

## 截图、文字与隐私

插件只围绕选中的目标窗口采集任务所需状态，但窗口截图和可访问性文字可能进入当前模型上下文。开始前关闭无关的敏感窗口，避免让目标窗口同时显示密码、密钥、医疗、财务或私人通信。

输入文字不会作为明文出现在审批摘要中，但最终应用仍会接收你授权输入的内容。提交、发送或上传前，应检查目标应用、接收方和数据范围。

## 与 Chrome 的分工

| 需求 | 推荐能力 |
| --- | --- |
| 网页文字、DOM、表单、标签页和登录态 | Chrome |
| Windows 原生应用和桌面画布 | Windows 电脑控制 |
| 代码、项目文件和命令 | 文件或 Shell 工具 |
| 云服务中的结构化对象 | Connector 或 API |

即使 Chrome 也是 Windows 应用，普通网页任务仍应使用 Chrome 插件。只有页面能力无法触达的浏览器原生界面，并且不涉及安全警告、认证或敏感设置时，才考虑桌面控制。

## 常见问题

### 没有出现蓝色安全边框

插件会把安全提示视为桌面访问的硬性前提。若任务已经停止，重新安装或更新插件、重启 Anybox 后再试；不要尝试关闭提示组件。

### 找不到目标窗口

先手动打开应用并进入目标页面，再告诉 Agent 精确的应用名和窗口标题。启动器、欢迎页和主窗口可能是不同窗口。

### 窗口被遮挡或焦点变化

让 Agent 重新观察并激活目标窗口。不要要求它沿用上一次截图的坐标继续点击。

### 桌面锁定或出现受保护提示

请自行解锁并处理认证、UAC 或系统权限界面。完成后回到普通应用窗口，再开始新的 Computer Use 请求。

### 按 Esc 后任务停止

这是预期的紧急停止行为。先检查应用是否发生了部分修改，再明确说明从哪个状态继续。
