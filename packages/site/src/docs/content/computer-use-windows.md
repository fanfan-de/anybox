# Windows 电脑控制

Windows 电脑控制让 Agent 观察并操作一个指定的 Windows 应用窗口，适用于没有 Connector、API 或稳定命令接口的桌面软件。

> 当前支持 Windows 11 x64。控制期间所有显示器会出现蓝色边框和“按 Esc 停止”提示；提示无法显示时不会继续访问桌面。

## 安装与任务范围

1. 在“插件”中安装 `computer-use-windows`，并为当前项目启用。
2. 先打开目标应用。
3. 在请求中指定唯一窗口、允许动作和停止点。

> 仅操作已打开的记事本窗口，填入以下内容，并停在保存之前。

普通网页优先使用 Chrome；代码与命令使用文件或 Shell 工具；有结构化接口时优先 Connector 或 API。

## 操作机制

每一步都会：列出窗口、选择目标、获取最新截图与可访问性信息、执行一个动作、重新观察结果。观察状态只能授权一个动作；布局、焦点或遮挡变化后必须重新观察，不能复用旧坐标。

按物理键盘 `Esc` 可立即停止。停止后应用保留当前状态，继续前应先检查是否产生部分修改。

## 权限与禁止范围

发送、提交、删除、上传和安装等高影响动作会在执行前要求一次性确认。插件不会操作：

- Anybox、终端、PowerShell、命令提示符或“运行”窗口。
- 登录、密码、验证码、密码管理器、UAC 或安全桌面。
- 系统安全与隐私设置、付款、CAPTCHA 或浏览器安全警告。
- 锁屏及完整性级别高于 Anybox 的受保护窗口。

窗口截图和可访问性文字可能进入模型上下文。关闭无关敏感窗口，并在发送、提交或上传前核对应用、接收方和数据范围。

## 能力分工

| 需求 | 推荐能力 |
| --- | --- |
| 网页、表单、标签页和登录态 | Chrome |
| Windows 原生应用和画布 | Windows 电脑控制 |
| 代码、文件和命令 | 文件 / Shell 工具 |
| 云服务结构化对象 | Connector / API |

## 排障

- 蓝色边框未出现：更新或重装插件并重启 Anybox，不要绕过提示。
- 找不到窗口：手动打开目标页面，并提供准确的应用名和窗口标题。
- 焦点或布局变化：让 Agent 重新观察。
- 出现锁屏、认证或 UAC：由你处理后，再发起新请求。
