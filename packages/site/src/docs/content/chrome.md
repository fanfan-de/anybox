# Chrome 插件

Chrome 插件让 Agent 在你明确要求时使用真实的 Google Chrome。它适合依赖现有标签页、登录状态、浏览器扩展或网页可见界面的任务，例如检查已登录的后台、填写网页表单、测试本地站点和保留最终结果页。

> Chrome 可以读取和操作当前页面。网页内容、截图和你允许填写的信息可能进入当前模型上下文；处理私人账号时，应只开放完成任务所需的页面与数据。

## 什么时候使用 Chrome

优先使用 Chrome 的场景包括：

- 任务明确要求“在 Chrome 中”打开、查看或操作网页。
- 需要沿用你已经登录的网站会话或当前打开的标签页。
- 需要检查页面布局、可见状态、弹窗、加载过程或交互结果。
- 需要点击、滚动、填写、选择、下载或截取网页画面。
- 需要测试本地开发站点，并从用户实际看到的界面确认结果。

如果任务只是读取结构化数据、搜索云端文件或管理某个平台对象，优先使用对应 Connector、API 或命令行工具。它们通常更稳定，也更容易限制访问范围。只有这些方式无法完成任务、现有 Chrome 状态很重要，或仍需网页交互时，再使用 Chrome。

## 安装并为项目启用

1. 从 Anybox 左侧导航打开「插件」。
2. 搜索 `Chrome`，阅读插件详情中的权限范围，然后点击「安装」。
3. 在当前项目顶部菜单的插件选择器中启用 `Chrome`。
4. 打开 Google Chrome，确认 Anybox Chrome 扩展已经安装、启用并处于连接状态。
5. 新建任务并明确说出“使用 Chrome”，同时给出目标网站和期望结果。

安装插件时，Anybox 会注册插件包自带的本机通信组件。插件与浏览器扩展缺一不可；如果扩展未安装、被停用或版本过旧，Agent 会停止网页操作并提示你处理连接，而不会换用其他浏览器绕过问题。

## 推荐的任务写法

把目标、浏览器、站点和停止边界写清楚，Agent 更容易选择正确标签页并在关键动作前停下。

- “使用 Chrome 打开本地站点 `http://localhost:5173`，检查移动端导航并截图，不要修改数据。”
- “在 Chrome 中查看我已经登录的后台，把本周失败任务整理成列表，不要重新运行。”
- “使用 Chrome 填好这份表单，提交前停下来让我确认。”
- “检查当前标签页为什么没有显示保存成功，并告诉我页面上实际出现了什么。”

只提供网址并不一定表示必须使用 Chrome。如果真实浏览器状态很重要，请在任务中直接点名 Chrome。

## Agent 可以做什么

连接成功后，Agent 可以在受控标签页中：

- 列出、打开、选择和切换标签页。
- 导航、前进、后退、刷新并等待页面完成变化。
- 读取可见页面结构、可访问名称和文本。
- 按语义定位按钮、链接、输入框和其他控件。
- 点击、输入、选择、滚动、等待下载或文件选择器。
- 获取截图并用页面状态验证操作结果。

Agent 创建的临时标签页会按任务管理。最终结果页可以保留给你检查；需要你登录或确认的页面可以作为交接页保留。你原本打开的标签页不会因为任务结束而被自动关闭。

## 权限与隐私边界

Chrome 插件不会读取 Cookie、Local Storage、浏览器配置目录、密码、令牌或其他凭据存储。它也不提供任意页面 JavaScript 或无限制的 Chrome DevTools Protocol 通道。

以下动作可能触发额外审批或要求你接手：

- 向敏感字段填写个人信息、密码或验证码。
- 从本机选择文件并上传到网站。
- 发送消息、提交表单、发布内容、购买、删除或修改权限。
- 接受摄像头、麦克风、位置、下载或扩展安装等浏览器权限。

审批时检查目标网站、账号、将要发送的数据和动作后果。验证码、登录阻塞或安全提示需要你处理时，Agent 应保留当前页面并明确交接，而不是改用其他网站规避限制。

## 与 Windows 电脑控制（Computer Use）的区别

| 任务 | 推荐能力 |
| --- | --- |
| 网页 DOM、页面文字、表单和标签页 | Chrome |
| 依赖现有 Chrome 登录状态的网页任务 | Chrome |
| Windows 原生应用、画布或桌面控件 | Windows 电脑控制 |
| 浏览器原生界面且 Chrome 页面能力无法覆盖 | 谨慎使用 Windows 电脑控制 |
| 云端对象的结构化读取或批量操作 | 对应 Connector 或 API |

不要为了统一流程而让 Windows 电脑控制点击普通网页。Chrome 对网页结构的理解更准确，也更容易验证操作结果。

## 常见连接问题

### 提示安装或启用扩展

打开 Chrome 的扩展管理页，确认 Anybox Chrome 扩展已安装并启用。处理完成后回到原任务，让 Agent 重试连接。

### 提示扩展需要更新

更新 Anybox Chrome 扩展后再试。插件会校验浏览器端能力版本，不会在版本不匹配时继续发送操作。

### 提示修复本机组件

先在 Anybox 的插件页面重新安装或修复 Chrome 插件，再完全退出并重新打开 Chrome。不要手工复制本机通信配置。

### Chrome 没有登录目标网站

请在 Chrome 中自行完成登录，然后告诉 Agent 已准备好。Agent 不会读取保存的密码，也不应改用搜索结果或其他网站绕过登录。

### 页面操作后结果不确定

让 Agent 重新读取页面状态，不要直接重复点击。页面跳转、刷新或 DOM 更新后，旧控件位置可能已经失效。
