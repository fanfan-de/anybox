# Chrome 插件

Chrome 插件让 Agent 使用你现有的 Google Chrome 标签页、登录状态和可见页面，适合网页交互与真实浏览器验收。

> 网页内容、截图和输入信息可能进入模型上下文。只开放任务需要的页面与数据。

## 安装与使用

1. 在 Anybox 的“插件”中安装并为当前项目启用 Chrome。
2. 确认 Anybox Chrome 扩展已在浏览器中安装、启用并连接。
3. 在请求中明确写出 Chrome、目标网站、预期结果和停止点。

示例：

> 使用 Chrome 打开 `http://localhost:5173`，检查移动端导航并截图，不要修改数据。

Agent 可以切换标签页、导航、读取页面结构、点击、输入、选择、滚动、等待下载并截图。涉及提交、发送、上传、购买、删除或改权限时，应在动作前确认。

## 安全边界

Chrome 不读取 Cookie、浏览器存储、配置目录、已保存密码或令牌，也不提供任意页面 JavaScript 或无限制 DevTools 通道。

登录、验证码或安全提示需要你处理时，Agent 会保留页面并交接。操作后状态不确定时，应重新读取页面，不要直接重复点击。

## 选择正确能力

| 任务 | 推荐能力 |
| --- | --- |
| 网页 DOM、表单、标签页和现有登录态 | Chrome |
| Windows 原生应用和桌面画布 | Computer Use Windows |
| 云服务结构化数据或批量对象 | Connector / API |
| 代码、文件和命令 | 文件 / Shell 工具 |

## 连接问题

- **扩展缺失或过旧**：在 Chrome 扩展页安装、启用或更新 Anybox Chrome。
- **本机组件异常**：从 Anybox 重新安装或修复插件，然后完全重启 Chrome。
- **网站未登录**：自行登录后再让 Agent 继续；Agent 不会读取保存的密码。
