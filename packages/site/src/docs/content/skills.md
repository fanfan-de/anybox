# Skills

Skill 是 Agent 按需加载的可复用说明和资源，适合保存项目规范、测试流程、发布步骤和检查清单。它不会绕过工具权限。

## 打开 Skills 工作台

- **本地**：编辑用户级或项目级 Skill；插件 Skill 只读。
- **发现**：搜索外部来源并检查文件、版本和安全信息。
- **已下载**：启用、更新、回滚或 Fork 受管 Skill。

| 来源 | 位置或条件 | 适合内容 |
| --- | --- | --- |
| 项目级 | `<项目>/.anybox/skills/<名称>/SKILL.md` | 当前仓库规则 |
| 用户级 | `~/.anybox/skills/<名称>/SKILL.md` | 跨项目个人流程 |
| 插件 | 已安装、启用并被项目选择 | 插件配套说明 |
| 受管下载 | 从“发现”或 URL 安装 | 版本化第三方 Skill |

## 创建本地 Skill

在“Skills → 本地”中新建 Skill，选择用户级或项目级，填写清晰的名称、触发条件和步骤。例如：

```md
---
name: release-check
description: 发布前检查构建、测试、版本与产物。
---

# Release Check

1. 读取仓库发布说明。
2. 运行类型检查和测试。
3. 构建并核对产物。
4. 发布前汇报版本、风险和未完成项。
```

一个 Skill 聚焦一类流程，并写明顺序、成功条件与停止条件。保存后在新会话中用匹配任务验证触发。

## 下载与启用

1. 在“发现”中搜索或从 URL 安装，并先审阅发布者、文件、版本和 Security。
2. 下载后进入“已下载”，打开“允许 Agent 使用”。
3. 确认当前项目已选择该 Skill，再用只读任务验证。

“已下载”不等于“已启用”；启用后也只会在任务匹配时加载。更新前查看文件差异；Fork 到本地后将不再自动跟随上游。

## 安全与排障

- 不要在 `SKILL.md`、示例或资源中保存密钥和私人数据。
- 外部 Skill 可能含过时或危险指令；扫描正常不等于绝对安全。
- 本地 Skill 缺失时，确认目录直接包含 `SKILL.md` 并刷新项目。
- 下载后未触发时，检查启用状态、项目选择和 description 是否准确。
- 插件 Skill 缺失时，确认插件已安装、启用并被当前项目选择。
