# FAQ

## Anybox 是什么？

Anybox 是面向软件开发与日常办公的开源 AI Agent 桌面工作台，统一管理项目、会话、模型、工具、权限、Skills、MCP 和插件。

## 支持哪些平台？从哪里下载？

桌面端主要支持 Windows x64、macOS Apple Silicon 和 Linux x64，目前处于 Early Access。Android 与 iOS 仍在开发和早期测试。安装包、系统要求和平台状态以 GitHub Releases 的实际资产为准。

## 必须使用云端模型吗？

不必。自定义 Provider 可连接团队网关或本机兼容端点，但 Anybox 不内置本地推理引擎，本地服务需要自行安装和维护。

## 如何配置或切换模型？

在“设置 → 服务商”登录或填写 API Key 并测试连接，再到“设置 → 模型”选择主模型和可选小模型。会话顶部可覆盖全局选择。模型目录动态更新，以当前应用和账户权限为准。

## Anybox 会自动修改项目吗？

默认模式会按工具、参数、路径和风险自动允许、询问或拒绝，并非每次写入都弹窗。陌生任务可先要求只读或使用 Planning 模式，执行后检查 Diff。

## 完全访问是否没有限制？

不是。Critical 风险、项目外副作用和部分敏感路径操作仍会被阻止。

## 项目、会话和任务是什么关系？

项目对应本地目录、Git 仓库或 SSH 工作区；一个项目可有多个会话。任务是会话内的结构化执行状态，不是独立项目管理看板。Git 项目可用 worktree 隔离并行工作。

## Skill、MCP 和插件有什么区别？

Skill 提供说明和资源；MCP 提供可调用工具与数据；插件可打包 Skill、MCP、Connector 和展示信息。受管 Skill 下载后还需启用并被项目选择。

## 凭据和数据如何处理？

手动保存的 Provider 凭据位于本机 Agent 管理的数据中，不应假定一定使用系统钥匙串或额外加密。模型、MCP、Connector、市场和云中继可能接收任务所需数据；不要在项目、Prompt 或 Skill 中写入密钥。

## 本地保存什么？“优化存储”会删会话吗？

项目、会话、消息、任务、权限记录和多数运行状态保存在本机 Agent 数据目录。“优化存储”主要清理过期 Trace、未引用工具产物并整理 SQLite，不以删除正常会话历史为目的。

## 模型测试失败或 Agent 无法连接怎么办？

模型问题检查凭据、额度、网络、API Base URL、模型 ID 和限制。Agent 默认地址为 `http://127.0.0.1:4096`，健康检查为 `/healthz`；同时检查端口、自定义地址和安全软件。

## 为什么操作被直接拒绝，没有审批按钮？

常见原因是只读策略、计划未获批、路径超出项目、敏感文件或 Critical 风险。审批不能绕过自动安全策略。

## 如何报告问题？

使用应用内 `/report`，确认文件数量、大小、目标和脱敏提示后再上传。脱敏是尽力而为，问题描述中仍不得包含密钥、Token 和私人数据。

文档与应用不一致时，以当前安装版本的界面、对应 GitHub Release 和仓库源码为准。
