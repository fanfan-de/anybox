# FAQ

## Anybox 是什么？

Anybox 是面向本地项目的开源 AI Agent 桌面工作台。它把项目、持久会话、模型、工具、终端、权限、Skills、MCP 和插件放在同一个工作空间中。

## 当前支持哪些平台？

主要桌面目标是 Windows x64、macOS Apple Silicon 和 Linux x64，均处于 Early Access。Linux Release 通常提供 AppImage，部分版本也提供 Debian 包；实际资产以每个 GitHub Release 为准。

## Android 和 iOS 可以直接下载吗？

移动客户端正在开发与早期测试，仓库中已有 Android/iOS 源码和配对能力。是否提供公开安装包、支持哪些系统版本，应查看最新 GitHub Releases，不能把开发脚本等同于正式发布。

## 从哪里下载安装包？

从项目的 GitHub Releases 页面选择版本和平台资产。下载前核对操作系统、CPU 架构、版本说明和可用校验信息；并非每个版本都一定包含所有平台。

## 是否必须使用云端模型？

Anybox 可连接多个云端 Provider，也可把自定义 Provider 指向团队网关或本机运行的兼容端点。不过 Anybox 当前不内置本地模型推理引擎，本地端点需要由你单独安装和维护。

## 如何配置模型？

在“设置 → 服务商”登录或填写 API Key，点击“测试连接”；成功后到“设置 → 模型”选择主模型和可选的小模型。单个会话还可以覆盖全局模型选择。

## 为什么文档不列出全部模型？

服务商与模型目录会动态刷新，模型名称、能力、上下文、状态和价格元数据可能变化。以应用当前目录、服务商公告和账户实际权限为准。

## Anybox 会自动修改项目吗？

默认模式会根据工具、命令、路径和风险自动允许、询问或拒绝，因此不是所有写入都会弹窗。开始陌生任务时，可先使用只读 Prompt 或 Planning 模式，并在执行后检查 Diff。

## “完全访问”是否没有限制？

不是。完全访问会减少一般询问，但 Critical 风险、活动项目之外的副作用操作和部分敏感路径操作仍会被阻止。它不应作为绕过项目边界的方式。

## 项目、会话和任务是什么关系？

项目对应目录、Git 仓库或 SSH 工作区；项目中可保存多个会话。任务是会话里的结构化执行状态，可记录负责人、依赖、当前项和阻塞项，不是独立的项目管理看板。

## 支持 SSH 和 Git worktree 吗？

支持打开远程 SSH 文件夹。Git 项目还可创建独立 worktree，用于隔离并行任务；远程工作区可用工具会与本地工作区不同。

## Skills、MCP 和插件有什么区别？

Skill 提供说明和资源；MCP 连接可调用的工具与数据资源；插件可组合 Skills、MCP、Connector 和界面元数据。三者的实际操作仍受项目选择和权限策略约束。

## Skill 下载后为什么没有生效？

受管 Skill 下载后默认不会被 Agent 加载。请到 Skills 的“已下载”页面启用“允许 Agent 使用”，并检查当前项目的 Skill 选择；插件 Skill 还要求插件已启用并被项目选择。

## 凭据保存在哪里，是否使用系统密钥链？

手动保存的 Provider 凭据位于本机 Agent 管理的应用数据中，并在系统支持时收紧文件访问权限。当前不应假定它一定使用系统钥匙串或额外文件加密；不要把密钥写入项目、Prompt 或 Skill。

## 哪些数据会离开本机？

调用模型时，Prompt、会话上下文及任务所需的文件或工具内容会发送给所选 Provider。MCP、Connector、Web Fetch、插件或 Skill 市场、模型目录刷新和移动端云中继也可能访问外部服务。

## 本地保存了哪些数据？

项目、会话、消息、任务、归档、权限记录和多数运行状态保存在本机 Agent 数据目录。可在“设置 → 存储”查看数据库、Trace、工具产物和相关路径。

## “优化存储”会删除聊天记录吗？

存储维护主要清理超过保留期的运行 Trace、未引用的工具产物并整理 SQLite 空间，不以删除正常消息或会话历史为目的。运行任务存在时，优化可能暂不可用。

## 模型测试失败怎么办？

检查 API Key 或登录状态、账户额度、代理与防火墙、API Base URL、模型 ID、区域和速率限制。刷新服务商目录后，再确认会话没有覆盖成旧模型。

## Agent 无法连接怎么办？

默认本地 Agent 地址是 `http://127.0.0.1:4096`，健康检查为 `/healthz`。检查托管 Agent 是否仍在启动、端口是否占用、自定义 Agent 地址是否正确，以及安全软件是否拦截本地服务。

## 为什么某个操作被直接拒绝而没有审批按钮？

常见原因包括当前会话或 Agent 使用只读策略、计划尚未获批、路径超出活动项目、命中敏感文件或被判定为 Critical 风险。审批只用于允许用户决定的操作，不会为自动安全策略已经禁止的操作提供绕过入口。

## 如何提交诊断报告？

使用应用内 `/report` 流程查看待上传文件数、大小、目标和脱敏提示，再主动确认上传。脱敏是尽力而为，请勿在问题描述或会话中加入密钥、Token 和私人数据。

## 下载或文档内容与应用不一致怎么办？

先以当前安装版本的界面、对应 GitHub Release 和仓库源码为准。Anybox 处于快速迭代期，平台状态、模型目录和移动能力可能早于或晚于站点文案更新。

## 第一次使用后应该继续读什么？

先阅读“模型供应商”完成连接与数据边界确认，再阅读“Skills”沉淀项目规则。只有在任务确实需要外部工具或服务时，再配置 MCP 和插件。
