# 项目、工作区与会话

Anybox 用项目限定文件范围，用工作区承载操作界面，用会话保存持续协作。

| 概念 | 含义 |
| --- | --- |
| 项目 | 一组相关文件和任务，通常对应主动打开的目录 |
| 工作区 | 项目树、会话、执行记录和工具面板组成的桌面环境 |
| 会话 | 消息、工具调用、权限请求、错误和变更记录 |

本地目录与 SSH 工作区可用的 Shell 等工具可能不同。

## 组织任务

1. 打开能完整承载任务的最小目录，并核对路径。
2. 在目标项目下新建会话。
3. 首条消息写清目标、读写范围和完成标准。
4. 不相关的目标使用不同会话；继续旧任务前先看最近状态和未完成项。

目录过大会增加噪声和暴露范围。目标或权限边界明显变化时，创建新会话比继续堆叠历史更清晰。

## 检查执行

ThreadView 不只是聊天记录，还会显示工具调用、来源、权限、文件变更、工作流状态和错误。已完成内容可能折叠；验证时应展开记录并检查实际 Diff 或测试结果。

切换会话不会自动停止运行中的任务。需要停止时，请使用明确的停止操作并等待状态更新。

## 数据与边界

打开项目只建立上下文，不会授权任意命令或写入。文件系统权限、工具策略和调用审批仍然生效。

会话历史保存在本机 Agent 数据中。长会话可能压缩旧上下文，但不会删除项目文件。使用云端模型或 SSH 时，数据还受模型服务商和远程主机的权限与政策约束。
