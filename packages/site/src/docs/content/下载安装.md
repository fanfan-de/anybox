# 快速开始

## 下载安装

桌面端目前处于 Early Access。安装包以 GitHub Releases 为准：

| 平台 | 发布形式 |
| --- | --- |
| Windows x64 | Windows 安装包 |
| macOS Apple Silicon | macOS 安装包 |
| Linux x64 | AppImage；部分版本含 Debian 包 |
| Android / iOS | 开发与早期测试；以具体 Release 为准 |

从最新 Release 下载与系统和架构匹配的文件，并核对发布说明、发布者和可用校验信息。并非每个版本都包含所有平台。

## 完成首次配置

1. 安装并启动 Anybox，保留默认本地 Agent 设置。
2. 选择“打开文件夹”，打开一个本地目录或 Git 仓库；服务器目录使用“打开远程文件夹”配置 SSH。
3. 打开“设置 → 服务商”，登录或填写 API Key，然后执行“测试连接”。
4. 打开“设置 → 模型”，选择主模型。
5. 返回项目并新建会话。

服务商和模型目录会动态更新。新模型未出现时，刷新服务商目录后再检查模型页。

## 第一次任务

先验证只读链路：

```text
请阅读这个项目的 README 和目录结构，说明它如何启动；暂时不要修改文件。
```

确认项目、模型、工具调用和最终结论都正确后，再进行写入任务。

## 权限与数据

- 默认模式会根据工具、参数、路径和风险自动允许、询问或拒绝；并非每次写入都弹窗。
- Critical 风险、项目外副作用和部分敏感路径操作会被阻止，完全访问模式也不例外。
- 模型请求会把 Prompt、会话上下文及任务所需内容发送给所选服务商；MCP、Connector、插件和市场也可能访问外部服务。

## 启动问题

- **Agent 不可用**：检查本地服务 `http://127.0.0.1:4096/healthz`、端口占用和安全软件。
- **模型测试失败**：检查凭据、额度、网络代理、API Base URL 和模型状态。
- **项目无法打开**：确认目录存在、账户有权限，且选择的是文件夹。
- **缺少平台安装包**：查看其他近期 Release，不要安装错误架构的文件。
