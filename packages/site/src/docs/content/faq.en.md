# FAQ

## What is Anybox?

Anybox is a desktop AI agent workspace for local projects. The repository also contains the local agent service, desktop application, and supporting website.

## Which platforms are supported?

The website provides Early Access installers for Windows x64, macOS Apple Silicon, Linux x64, and Android. The Linux build includes the full Cinema/Deliver feature set and is available as an AppImage and Debian package.

## Must I connect a cloud model?

Not necessarily. Anybox is designed for multiple providers and flexible configuration. You can connect a cloud model or a custom agent service that matches your project deployment.

## Will it modify my project automatically?

Anybox works with local projects. Review file changes, terminal commands, and tool calls in the session interface, and explicitly approve operations that require permission.

## What if a download link does not work?

Open GitHub Releases directly and select the latest installer for your platform.

## What documentation is coming next?

Useful future topics include detailed settings, MCP server configuration, permission approvals, the terminal panel, session export, team collaboration, and release workflows.
