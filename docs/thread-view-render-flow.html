ThreadView 数据到渲染流程

当前 ThreadView 已删除过程折叠模型。Assistant trace item 不再先进入旧的过程抽屉，而是在 thread-display-rows.ts 中按展示语义拆成独立 row，最终仍由 TraceItemView 根据 item.kind 分发具体 renderer。

1. Source

ConversationTurnMap 是源数据，turn 内包含 user / assistant message。

2. Projection

deriveActiveMessages() 生成 ThreadView 消费的 ThreadMessage[]。

3. Rows

buildThreadDisplayRows() 负责把 assistant items 拆成语义 row。

4. Render

renderDisplayRow() 只按 row kind 选择外层结构，具体内容继续交给 TraceItemView。

保留行为

  • trace visibility 过滤仍在 row builder 中执行。
  • stream-inserted user message 继续按 assistant item index 插入。
  • folded intermediate assistant item 仍归属 final assistant owner，并保留 source metadata。
  • file-change 继续摘要化；不同 source message 的 file-change 不合并。

已删除行为

  • 不再生成 process header。
  • 不再维护 process trace 展开/折叠状态。
  • 不再有过程折叠按钮、chevron 或折叠动画。
