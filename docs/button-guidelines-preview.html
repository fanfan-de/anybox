Anybox Button Guidelines Preview

入口页只负责并排展示两个独立 iframe；每个 iframe 都直接加载 Anybox 的真实 token 文件，并在自身根节点切换主题。

source: packages/desktop/src/renderer/src/styles/tokens.css
Light iframe root: data-theme="light"
Dark iframe root: data-theme="dark"

Token wiring: 子页组件样式只消费 --semantic-button-*。这些 alias 在子页本地定义，但全部映射到真实 tokens.css 已存在的 runtime token。

Theme isolation: 两个 iframe 各自拥有独立 :root，因此可以同时显示 light/dark，而不需要在同一 document 里复制整套主题映射。
